# QR 탭 — 만료 없는 URL 담은 QR 코드 생성

날짜: 2026-08-05
참고: https://nuung.github.io/qrcode-gen/ (사용자 제시 요구사항 기반)

## 목적

로그인·서버 없이 브라우저 안에서만 도는 QR 생성기. **리다이렉트가 아니라 URL
자체를 코드에 담아** 만료가 없다 — 링크가 살아 있는 한 QR도 살아 있다.
URL·로고가 어디로도 전송되지 않는다.

## 확정된 기술 결정

- **인코더: qrcode-generator 1.4.4 (Kazuhiko Arase, MIT) 번들** — `vendor/qrcode.js`,
  pdf.js 전례와 같은 지연 로드. 인쇄물 QR은 스캔 실패가 치명적이라 십수 년 검증된
  구현을 쓴다(요구사항이 'MIT 써드파티' 명시 허용). ES5·의존성 0·UTF-8 내장.
  버전 자동(typeNumber 0), Byte 모드 + UTF-8 stringToBytes.
- 나머지는 자체 구현: UTM 빌더, 로고 합성(캔버스), 색·대비 경고, PNG 스케일링,
  SVG 문자열 생성.
- **검증**: 하네스에서 jsQR(MIT)로 산출 캔버스·SVG를 **실제 디코드**해 왕복 확인
  (run.mjs `--inject`로 페이지에 주입 — 앱에는 포함 안 함).

## UI (탭: GIF와 Base64 사이, key 'qr')

카드 하나, Base64 탭의 card-head 밴드 패턴 재사용.

- **URL 또는 텍스트** 입력 (비-URL 텍스트도 그대로 인코딩)
- **UTM 캠페인 파라미터** (접이식 details):
  - 프리셋 칩: 직접 입력 · 📘 페이스북(facebook/social) · ✉️ 뉴스레터(newsletter/email)
    · 🖨️ 인쇄물(print/qr) · ▶️ 유튜브(youtube/video) — source/medium 채움, 수정 가능
  - utm_source/medium/campaign/content/term 5필드 전부 지원
  - 최종 URL 실시간 미리보기. 기존 쿼리(`?`→`&`)·해시(# 앞 삽입) 보존.
    입력이 http(s) URL이 아니면 UTM 미적용.
- **옵션**: 색상(코드/배경 컬러 픽커 + 낮은 대비·반전 경고), 오류 정정 L/M/Q/H
  (기본 M), PNG 크기 300/600/900/1200(기본 600), 로고(이미지 파일 → 중앙 22%
  흰 패드 위 합성, 넣으면 EC 자동 H 상향 + 안내, 제거 버튼)
- **미리보기** 캔버스(입력 디바운스 250ms 재생성) + 상태줄(버전·모듈·EC)
- **다운로드**: PNG(선택 크기 정확히), SVG(벡터, 로고는 data URI `<image>`),
  공유하기. 파일명 `qr-<호스트>.png/svg`.
- 콰이어트 존 4모듈. 탭에 이미지 드롭 → 로고로 라우팅.

## 검증 (headless + jsQR 실디코드)

1. URL 왕복: 렌더 캔버스 → jsQR 디코드 == 입력
2. UTM: 프리셋+campaign → 최종 URL 파라미터 정확, 해시·기존 쿼리 보존, 디코드 일치
3. 비-URL 텍스트에 UTM 미적용 · 한글 UTF-8 왕복
4. EC 칩: L↔H 버전(모듈 수) 변화 + 디코드 유지
5. 색: 어두운 모듈 픽셀 == 지정 전경색, 디코드 유지
6. 크기: 300·1200 정확 치수
7. 로고: EC 자동 H·중앙 픽셀 로고색·가림에도 디코드 성공
8. SVG: 래스터화 후 디코드 일치

## 부록 (2026-09-02, 콘텐츠 유형 드롭다운)

- 카드 헤더 오른쪽 상단 '만들 내용' 드롭다운: 🔗 URL·텍스트(기본) / 📞 전화 /
  💬 문자 / ✉️ 이메일 / 📶 와이파이 / 👤 연락처. 유형마다 입력틀 교체,
  URL 유형에만 UTM 노출.
- 페이로드 조립(자체 구현): tel:(공백 제거) · sms:+?body= · mailto:+subject/body ·
  WIFI:T:;S:;P:;(H:true) — \\ ; , : " 이스케이프, nopass면 P 생략 ·
  MECARD:N;TEL;EMAIL;NOTE. '담기는 내용: …' 실시간 미리보기로 정직하게 노출.
- 파일명 유형 반영(qr-tel·qr-wifi-<ssid>·qr-contact 등).
- 수정: 빈 필수값 렌더가 seq를 올리지 않아 직전 비동기 렌더가 결과를
  되살리던 레이스 — 빈 경로도 seq 무효화 (qr2 테스트가 검출).
