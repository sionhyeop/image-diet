# 일괄 크롭 탭 — 한 장에서 정한 크롭을 모든 이미지에

날짜: 2026-09-02

## 목적

여러 이미지를 올리고 **한 장(기준 이미지)에서 가장자리를 잘라내면, 나머지 전부에
똑같은 크롭을 적용**해 일괄 저장한다. 스크린샷 여백 제거·연속 캡처 정리 용도.

## 설계 결정

- **탭 이름 '일괄 크롭'** (key `crop`, 이미지 분할 옆) — 기능을 그대로 말해주는 이름.
- **크롭 정의 UX**: GIF 탭 영상 크롭과 동일한 '전체 프레임에서 테두리·모서리
  핸들(8개)을 안쪽으로 좁혀 나가기' + 안쪽 드래그 이동. 새 그리기 없음.
- **다른 크기 이미지엔 비율(%) 적용**: 크롭 사각형을 기준 이미지의 비율로 저장,
  각 이미지에 같은 비율로 적용. 전부 같은 크기(흔한 경우: 연속 스크린샷)면
  픽셀 단위로 동일. UI에 이 규칙을 정직하게 명시.
- **기준 이미지 교체**: 썸네일 스트립에서 클릭으로 선택 (기본 첫 장).
- **출력**: 형식 칩(원본 유지 기본 / WebP / JPEG / PNG) + 품질 슬라이더(무손실 제외),
  '모두 자르기' 버튼 → 결과 그리드(치수·용량) → 개별 저장 / ZIP / 비우기.
  파일명 `<원본이름>-crop.<확장자>`.
- 라우팅: 탭에 이미지 드롭·붙여넣기 → 트레이에 추가(이어 붙이기).

## 검증 (headless)

1. 크기 다른 3장 업로드 → 기본 크롭 = 전체
2. 핸들 드래그로 영역 축소 (포인터 이벤트 실측)
3. 25%,25%,50%,50% 크롭 적용 → 3장 치수 각각 비율대로, 픽셀 색 = 해당 사분면
4. 형식 칩(WebP) MIME 반영, ZIP 항목 수, 비우기
